- ADD_TASK
- MODIFY_TASK
- DEFER_TASK
- CANCEL_TASK

- ADD_DEPENDENCY
- REMOVE_DEPENDENCY

Allowed department values:
- CEO
- DEVELOPMENT
- MARKETING
- FINANCE

Rules:
1. Propose only legal, valid changes to unblock progress.
2. For ADD_TASK, use negative integer dependencies (-1, -2) if referencing other tasks created in the same proposal.
3. Do not modify or cancel already COMPLETED tasks.
4. Keep changes concise (max 5 changes per proposal).
5. Return ONLY the JSON object.
